# Agent Guidelines

## Project Folder Structure Rule

Before adding or creating any new file or directory in this repository:

1. **Check the Project Structure First**: Always consult the reference folder structure documented in [`README.md`](README.md) before creating any new file or directory. Ensure every new component, module, asset, test, or script is placed strictly according to this structure.
2. **Clarification Over Assumption**: If there is any ambiguity, doubt, or confusion regarding where a file should belong or if a new path/file is needed, **ask the user directly for clarification instead of deciding or assuming on your own**.
